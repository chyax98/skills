# 异常场景检查清单

> 系统性识别需求中缺失的负向场景

## 检查清单概览

```
异常场景
├── 1. 输入异常
│   ├── 空值/Null
│   ├── 格式错误
│   ├── 超长/超短
│   ├── 边界值
│   └── 恶意输入
│
├── 2. 状态异常
│   ├── 网络异常
│   ├── 服务异常
│   ├── 会话异常
│   └── 并发异常
│
├── 3. 数据异常
│   ├── 数据不存在
│   ├── 数据状态异常
│   ├── 数据冲突
│   └── 关联数据异常
│
├── 4. 权限异常
│   ├── 无权限
│   ├── 权限变更
│   └── 越权操作
│
└── 5. 业务异常
    ├── 规则违反
    ├── 流程异常
    └── 资源不足
```

## 1. 输入异常

### 1.1 空值/Null

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 必填字段为空 | 用户未填写提交 | 前端校验 + 提示"请填写XXX" |
| 可选字段为空 | 用户不填写提交 | 后端使用默认值/允许空值 |
| 传入 null | API 调用传 null | 后端校验 + 返回参数错误 |
| 空字符串 | 只有空格的输入 | trim 后判空 |
| 空数组/空对象 | 列表为空提交 | 根据业务判断是否允许 |

**检查提问**:
- "必填字段为空时如何提示？"
- "可选字段为空时用什么默认值？"

### 1.2 格式错误

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 手机号格式错误 | 非 11 位/非数字 | 正则校验 + 提示 |
| 邮箱格式错误 | 缺少 @/. | 正则校验 + 提示 |
| 身份证格式错误 | 位数错/校验位错 | 完整校验 + 提示 |
| 日期格式错误 | 非法日期字符串 | 解析失败提示 |
| URL 格式错误 | 缺少协议/非法字符 | 正则校验 + 提示 |
| JSON 格式错误 | 语法错误 | 解析失败提示 |

**检查提问**:
- "手机号的校验规则是什么？（纯数字？11位？1开头？）"
- "日期格式支持哪些？（YYYY-MM-DD？YYYY/MM/DD？）"

### 1.3 超长/超短输入

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 用户名太短 | < 最小长度 | 提示"用户名至少X位" |
| 用户名太长 | > 最大长度 | 截断/提示"用户名最多X位" |
| 密码太短 | < 最小长度 | 提示密码强度要求 |
| 文本内容超长 | > 数据库字段长度 | 前端限制 + 后端校验 |
| 文件名超长 | > 系统路径限制 | 截断文件名 |

**检查提问**:
- "用户名的长度限制？最少几位？最多几位？"
- "文本内容超长时是截断还是报错？"

### 1.4 边界值

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 数值 = 0 | 输入零 | 根据业务判断 |
| 数值为负 | 输入负数 | 数量类通常不允许 |
| 最小值 - 1 | 刚好低于下限 | 校验 + 提示 |
| 最大值 + 1 | 刚好超过上限 | 校验 + 提示 |
| 日期边界 | 1970/2038/闰年2月29 | 特殊日期处理 |
| 金额精度 | 小数位数超限 | 四舍五入/报错 |

**检查提问**:
- "数量为 0 时允许提交吗？"
- "金额支持几位小数？超出如何处理？"

### 1.5 恶意输入

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| SQL 注入 | 输入 `'; DROP TABLE` | 参数化查询 |
| XSS 攻击 | 输入 `<script>` | HTML 转义 |
| 路径遍历 | 输入 `../../etc/passwd` | 路径校验 |
| 命令注入 | 输入 `; rm -rf /` | 命令参数过滤 |
| CSRF | 伪造请求 | Token 验证 |

**检查提问**:
- "用户输入会在哪些地方展示？是否需要转义？"
- "文件上传的文件名如何处理？"

## 2. 状态异常

### 2.1 网络异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 网络断开 | WiFi/流量关闭 | 提示"网络不可用" + 离线模式 |
| 网络超时 | 响应超过 X 秒 | 提示"请求超时" + 重试按钮 |
| 弱网环境 | 网络延迟高 | 加载动画 + 超时提示 |
| 网络切换 | WiFi 切 4G | 检测网络变化 + 续传 |
| DNS 解析失败 | 域名无法解析 | 提示"无法连接服务器" |

**检查提问**:
- "网络超时的阈值是多少秒？"
- "断网时用户操作如何处理？离线缓存？"

### 2.2 服务异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 服务不可用 | HTTP 5xx | 提示"服务暂时不可用" + 重试 |
| 接口异常 | 返回非预期格式 | 容错处理 + 降级 |
| 依赖服务故障 | 第三方服务宕机 | 降级方案 + 告警 |
| 限流/熔断 | 请求过多被拒 | 提示"系统繁忙" + 排队 |
| 维护中 | 计划内停机 | 维护页面 + 预计恢复时间 |

**检查提问**:
- "服务不可用时展示什么？有降级方案吗？"
- "第三方服务（如短信）不可用时如何处理？"

### 2.3 会话异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| Token 过期 | 超过有效期 | 自动刷新/跳转登录 |
| 会话被踢 | 其他设备登录 | 提示"账号在其他设备登录" |
| 未登录访问 | 访问需登录页面 | 跳转登录 + 返回原页面 |
| 权限被撤销 | 管理员撤销权限 | 提示权限变更 + 退出 |

**检查提问**:
- "Token 有效期多长？过期后自动刷新还是重新登录？"
- "多端登录策略？踢掉旧设备还是拒绝新设备？"

### 2.4 并发异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 重复提交 | 快速点击两次 | 按钮防抖 + 接口幂等 |
| 并发修改 | 多人同时编辑 | 乐观锁 + 冲突提示 |
| 库存超卖 | 同时下单 | 库存锁定 + 扣减校验 |
| 数据竞争 | 读写时序错乱 | 事务隔离 + 重试 |

**检查提问**:
- "提交按钮防重复点击了吗？"
- "多人同时编辑同一数据如何处理？"

## 3. 数据异常

### 3.1 数据不存在

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 记录已删除 | 访问已删除数据 | 提示"数据不存在" |
| ID 不存在 | 伪造/过期 ID | 返回 404 |
| 关联数据删除 | 外键引用被删 | 级联处理/提示 |
| 分页越界 | 页码超过总页数 | 返回空列表/最后一页 |

**检查提问**:
- "访问已删除的数据时提示什么？"
- "分页请求超出范围时返回什么？"

### 3.2 数据状态异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 状态已变更 | 操作时数据状态变了 | 刷新 + 提示状态变化 |
| 非法状态流转 | 跳过中间状态 | 校验 + 拒绝 |
| 数据已锁定 | 被其他流程锁定 | 提示"数据被占用" |
| 数据已过期 | 超过有效期 | 提示过期 + 引导续期 |

**检查提问**:
- "操作时数据被其他人修改了怎么办？"
- "订单状态流转的约束是什么？"

### 3.3 数据冲突

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 唯一键冲突 | 重复的唯一值 | 提示"XXX已存在" |
| 版本冲突 | 乐观锁检测失败 | 提示冲突 + 手动合并 |
| 时间戳冲突 | 修改时间不一致 | 刷新 + 重试 |

**检查提问**:
- "手机号/邮箱已被注册时如何提示？"
- "并发修改检测到冲突时如何处理？"

### 3.4 关联数据异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 外键引用失效 | 关联数据被删 | 软删除/级联处理 |
| 主从数据不一致 | 延迟同步 | 最终一致性/重试 |
| 缓存与数据库不一致 | 缓存过期/失效 | 缓存更新策略 |

**检查提问**:
- "删除用户时，其关联数据如何处理？"
- "主数据变更时，关联数据如何同步？"

## 4. 权限异常

### 4.1 无权限

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 功能无权限 | 访问无权限功能 | 隐藏入口/禁用按钮/403 |
| 数据无权限 | 访问无权限数据 | 返回 403/空结果 |
| 操作无权限 | 执行无权限操作 | 提示"无权限" |

**检查提问**:
- "无权限时是隐藏按钮还是禁用按钮？"
- "无权限访问数据时返回什么？"

### 4.2 权限变更

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 操作中权限被撤销 | 管理员修改权限 | 实时生效/下次登录生效 |
| 角色变更 | 用户角色调整 | 刷新权限 + 提示 |
| 部门调整 | 用户部门变更 | 数据权限重算 |

**检查提问**:
- "权限变更是实时生效还是下次登录生效？"
- "角色变更时正在进行的操作如何处理？"

### 4.3 越权操作

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 水平越权 | 访问同级别他人数据 | 数据权限校验 |
| 垂直越权 | 普通用户执行管理操作 | 角色权限校验 |
| 权限提升 | 伪造高权限请求 | 后端强制校验 |

**检查提问**:
- "用户能否通过修改 URL 参数访问他人数据？"
- "后端是否校验操作权限，还是只信任前端？"

## 5. 业务异常

### 5.1 规则违反

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 业务规则不满足 | 不符合业务条件 | 提示具体原因 |
| 金额校验失败 | 金额计算不一致 | 拒绝 + 告警 |
| 时间限制 | 超出可操作时间 | 提示时间限制 |

**检查提问**:
- "业务规则校验失败时如何提示用户？"
- "是否有时间限制？（如：24小时内可取消）"

### 5.2 流程异常

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 前置步骤未完成 | 跳过必要步骤 | 引导回到正确步骤 |
| 流程超时 | 步骤间隔超时 | 提示重新开始 |
| 流程中断 | 用户中途退出 | 保存草稿/下次继续 |
| 回退限制 | 已不可回退状态 | 提示不可回退原因 |

**检查提问**:
- "用户中途退出，下次能否继续？"
- "订单支付超时后如何处理？"

### 5.3 资源不足

| 场景 | 触发条件 | 建议处理 |
|------|---------|---------|
| 库存不足 | 下单时库存没了 | 提示"库存不足" + 推荐相似 |
| 余额不足 | 支付时余额不够 | 提示充值/切换支付方式 |
| 配额用完 | 免费额度用尽 | 提示升级/购买 |
| 次数用完 | 操作次数超限 | 提示限制规则 |

**检查提问**:
- "库存不足时如何提示？预约通知？"
- "免费额度用完后的处理方式？"

## 使用指南

### 检查顺序

建议按以下顺序检查每个功能点：

1. **输入层**: 用户能输入什么？每种输入如何处理？
2. **网络层**: 网络出问题怎么办？
3. **服务层**: 后端出问题怎么办？
4. **数据层**: 数据出问题怎么办？
5. **权限层**: 权限出问题怎么办？
6. **业务层**: 业务规则出问题怎么办？

### 提问技巧

**"如果...会怎样"句式**:
- "如果用户输入为空会怎样？"
- "如果网络突然断了会怎样？"
- "如果数据被别人删了会怎样？"
- "如果用户没有这个权限会怎样？"

**"极端情况"探索**:
- "如果输入 10 万个字符会怎样？"
- "如果同时有 1000 人操作会怎样？"
- "如果数据量有 100 万条会怎样？"

### 记录格式

对每个识别的异常场景，记录：

```yaml
场景编号: E-XXX
功能点: [关联功能点]
场景分类: [输入异常/状态异常/数据异常/权限异常/业务异常]
场景描述: [异常场景具体描述]
触发条件: [如何触发这个场景]
当前处理: [需求中是否有说明，有则摘录]
建议处理: [建议的处理方式]
```
