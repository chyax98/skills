# 测试类型指南

## 类型概览

| 类型 | 核心目标 | 占比 |
|-----|---------|-----|
| **功能测试** | 业务逻辑验证 | 50-60% |
| 安全性测试 | 安全防护 | 5-10% |
| 性能测试 | 性能指标 | 5-10% |
| 易用性测试 | 用户体验 | 5-10% |
| 兼容性测试 | 跨环境运行 | 5-10% |
| 稳定性测试 | 长期运行 | 3-5% |
| 集成测试 | 模块协作 | 5-10% |

---

## 选择决策树

```
涉及多个模块协作？ → 集成测试
关注长期运行稳定？ → 稳定性测试
关注故障恢复？ → 可靠性测试
关注安全防护？ → 安全性测试
关注性能指标？ → 性能测试
关注跨环境运行？ → 兼容性测试
关注用户体验？ → 易用性测试
关注数据埋点？ → 埋点测试
关注 AI 输出？ → AI效果测试
关注硬件交互？ → 硬件效果测试
默认 → 功能测试
```

---

## 详细说明

### 功能测试
验证系统功能按需求正确实现：
- 业务逻辑正确性
- 数据处理准确性
- 边界条件处理
- 异常情况处理

### 安全性测试
验证安全防护能力：
- 认证和授权
- SQL 注入防护
- XSS 攻击防护
- 敏感数据保护

### 性能测试
验证性能指标：
- 响应时间
- 并发处理能力
- 吞吐量
- 资源使用率

### 易用性测试
验证用户体验：
- 界面布局
- 操作流程
- 提示信息
- 错误容错

### 兼容性测试
验证跨环境兼容性：
- 浏览器兼容
- 设备兼容
- 分辨率适配

### 稳定性测试
验证长期运行稳定性：
- 7x24 运行
- 内存泄漏检测
- 资源占用监控

### 集成测试
验证模块间协作：
- 接口调用
- 数据流转
- 第三方服务

## 扩展类型

| 类型 | 适用场景 |
|-----|---------|
| 可靠性测试 | 故障恢复、服务降级 |
| 可维护性测试 | 日志、监控、配置 |
| 可移植性测试 | 跨平台迁移 |
| 埋点测试 | 数据上报、行为追踪 |
| AI效果测试 | 模型输出质量 |
| 硬件效果测试 | 传感器、外设控制 |
