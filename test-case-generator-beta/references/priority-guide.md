# 优先级判定指南

## 优先级定义

| 优先级 | 定义 | 执行频率 |
|-------|-----|---------|
| P1 | 核心功能正向（冒烟测试） | 每次构建 |
| P2 | 基本功能正向 | 每日回归 |
| P3 | 核心功能反向（错误/边界） | 版本回归 |
| P4 | 基本功能反向（异常/边界） | 完整回归 |
| P5 | 不常用功能正反向 | 发布前 |

---

## 判断决策树

```
是核心业务流程？
├─ 是 → 是正向场景？
│       ├─ 是 → P1
│       └─ 否 → P3
└─ 否 → 是基本功能？
        ├─ 是 → 是正向场景？
        │       ├─ 是 → P2
        │       └─ 否 → P4
        └─ 否 → P5（不常用功能）
```

---

## 映射表

| 功能重要性 | 正向场景 | 反向场景 |
|-----------|---------|---------|
| 核心功能 | P1 | P3 |
| 基本功能 | P2 | P4 |
| 不常用功能 | P5 | P5 |

**口诀**：核心正向必P1，基本正向上P2，核心反向是P3，基本反向给P4，不常用都P5

---

## 功能等级判定

### 核心功能（10-15%）
失败导致系统核心价值丧失：
- 用户登录/注册
- 订单创建/支付
- 核心数据保存
- 关键业务流程

### 基本功能（60-70%）
失败影响体验但不阻塞核心：
- 列表/查询
- 修改个人信息
- 消息通知
- 数据导出

### 不常用功能（15-25%）
低频扩展功能：
- 高级搜索
- 批量操作
- 管理员功能
- 自定义配置

---

## 特殊场景

### 性能测试
- 核心功能性能 → P2
- 基本功能性能 → P4
- 极端压力测试 → P5

### 安全测试
- 认证授权 → P1/P2
- 注入防护 → P3
- 高级渗透 → P4

### 兼容性测试
- 主流环境 → P2
- 次要环境 → P4

---

## 目标分布

| 优先级 | 建议占比 |
|-------|---------|
| P1 | 10-15% |
| P2 | 25-35% |
| P3 | 20-30% |
| P4 | 15-25% |
| P5 | 5-10% |

---

## 常见错误

| 错误 | 正确 |
|-----|-----|
| 登录密码错误 → P2 | → P3（核心功能反向） |
| 修改个人信息 → P3 | → P2（基本功能正向） |
| 修改头像 → P1 | → P2（基本功能正向） |
