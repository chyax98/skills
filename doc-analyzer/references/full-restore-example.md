# 效能数据晾晒自动化方案分享

## 背景描述

在当今快速发展的技术环境中，企业的成功在很大程度上依赖于其研发和测试团队的效率。本项目旨在通过自动化的方式收集和分析研发过程中的关键指标。

## 整体架构设计

[图片描述: 系统架构流程图，采用树状结构设计。顶层为「研测过程效能自动化」，分为三个主要分支：
1. 按周：每周一获取本季度累计数据和上一个自然周数据 → 飞书机器人发送群消息进行效能数据预警
2. 效能统计面板：主动获取 → 输入指定时间区间、产品线 → 获取研测过程重要指标值
3. 按月/季度：自动化采集 → 数据处理 → 报告生成

数据源包含两部分：
- 研发数字化运营系统数据（通过 request 模拟登录获取）
- 飞书项目内数据（通过飞书 OpenAPI 获取）]

### 双ST认证登录

系统使用双 ServiceTicket 认证机制完成登录：

```python
def _login(self):
    """完整的双 ST 认证登录流程"""
    # 第一步：获取登录页面
    login_url = "https://sso.iflytek.com:8443/sso/login"
    self.session.get(login_url)

    # 第二步：提交登录表单
    login_data = {
        'username': finbi_auth["username"],
        'password': finbi_auth["password"],
    }

    # 禁用自动重定向以捕获 ST
    response = self.session.post(login_url, data=login_data, allow_redirects=False)
    # ...后续处理
```
