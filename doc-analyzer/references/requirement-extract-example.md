# 需求提取示例

以下是从一份 PRD 文档中提取需求的示例输出。

---

## 文档概述

- **文档类型**：技术方案 / 产品需求文档
- **产品名称**：效能数据晾晒自动化系统
- **版本**：v1.0
- **范围**：AI翻录硬件研发部效能数据采集与展示

## 功能模块

### 模块1：效能统计面板

**功能点**：

1. **数据筛选**
   - 描述：支持按时间区间、产品线筛选效能数据
   - 优先级：高
   - 验收标准：
     - 支持选择起始/结束日期
     - 支持选择产品线（翻译机/录音笔/AI翻录）
     - 查询响应时间 < 3秒

2. **研测过程重要指标展示**
   - 描述：展示冒烟测试成功率、缺陷验证通过率等核心指标
   - 优先级：高
   - 验收标准：
     - 指标值实时计算
     - 未达标指标红色高亮
     - 下方显示分析结论

3. **缺陷分布可视化**
   - 描述：按模块、迭代、责任人展示缺陷分布
   - 优先级：中
   - 验收标准：
     - 支持饼状图展示
     - 可切换不同维度

### 模块2：月度/季度报告

**功能点**：

1. **报告自动生成**
   - 描述：自动采集数据生成效能报告
   - 优先级：高
   - 验收标准：
     - 支持导入 JSON 数据
     - 生成 HTML 格式报告
     - 包含趋势图

### 模块3：群消息预警

**功能点**：

1. **定时推送**
   - 描述：每周一自动推送效能数据预警到飞书群
   - 优先级：中
   - 验收标准：
     - 自动获取上周数据
     - 不达标指标标红
     - 达标指标标绿

## 界面设计

| 页面名称 | 入口 | 主要功能 | 关键字段 |
|---------|------|---------|---------|
| 效能统计面板 | 首页 | 数据查询与展示 | 时间区间、产品线、指标表格 |
| 报告页面 | /report | 报告生成与展示 | 文件选择、指标表格、趋势图 |

## 数据指标

| 指标名 | 标准值 | 计算方式 |
|--------|--------|---------|
| 冒烟测试成功率 | ≥95% | 冒烟成功次数/冒烟总次数 |
| 缺陷验证一次通过率 | ≥90% | 一次验证通过数/验证总数 |
| 低级缺陷率 | ≤7% | 低级缺陷数/缺陷总数 |
| 严重缺陷率 | ≤10% | 严重缺陷数/缺陷总数 |
| 缺陷逃逸率 | ≤3% | 线上问题数/缺陷总数 |
| 冒烟自动化率 | ≥50% | 自动化冒烟数/冒烟总数 |
| 回归自动化率 | ≥60% | 自动化回归数/回归总数 |

## 技术约束

1. 数据源依赖研发数字化运营系统和飞书项目
2. 需要配置双 ST 认证登录凭证
3. 飞书 API 需要插件访问凭证
