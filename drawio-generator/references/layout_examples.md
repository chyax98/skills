# 布局约束示例

## 示例 1：水平流��

```
用户请求：画一个简单的登录流程

布局选择：水平流程（模板 A）

节点数量：5
节点尺寸：M (120×60)
间距：60px
起始点：(100, 200)

计算：
node1(登录)     x=100, y=200
node2(验证)      x=100+120+60=280, y=200
node3(数据库)    x=280+120+60=460, y=200
node4(令牌)      x=460+120+60=640, y=200
node5(完成)      x=640+120+60=820, y=200

页面尺寸：
内容宽度 = 1000px (节点1.x + 节点5.width + 100)
内容高度 = 460px (节点5.y + 节点5.height + 200)
实际使用：1200×800
```

## 示例 2：垂直层级

```
用户请求：画一个三层架构

布局选择：垂直层级（模板 B）

第一层：1个节点 L(160×80) - 前端
第二层：2个节点 M(120×60) - API网关、负载均衡
第三层：1个节点 L(160×80) - 数据库

计算：
层1：
  宽度 = 160
  前端.x = (1200-160)/2 = 520, y = 100

层2：
  宽度 = 120+60+120 = 300
  网关.x = (1200-300)/2 = 450, y = 100+80+120 = 300
  负载.x = 450+120+60 = 630, y = 300

层3：
  宽度 = 160
  数据库.x = 520, y = 300+60+120 = 480
```

## 快速计算技巧

### 1. 对齐坐标

```
对任意数值向上取整到10的倍数：
round(x/10) * 10

例：123 → 120
    127 → 130
    55 → 50
```

### 2. 居中计算

```
单个节点居中：
center_x = (container_width - node_width) / 2

多个节点居中：
total_width = Σ(node_width) + (n-1) * spacing
start_x = (container_width - total_width) / 2
```

### 3. 页面尺寸

```
最小页宽：800
最小页高：600

实际页宽 = max(最右x + 200, 800)
实际页高 = max(最下y + 200, 600)
```

## 常见错误修正

### 错误1：节点不在网格上
```
❌ x=123, y=456
✅ x=120, y=460 (对齐到10的倍数)
```

### 错误2：间距不一致
```
❌ node1.x=100, node2.x=160 (间距60)
❌ node2.x=160, node3.x=230 (间距70)  # 不一致
✅ node1.x=100, node2.x=180 (间距80)
✅ node2.x=180, node3.x=260 (间距80)  # 一致
```

### 错误3：同层节点未对齐
```
❌ node1.y=100, node2.y=105  # 未对齐
✅ node1.y=100, node2.y=100  # 同y坐标
```

### 错误4：使用了非标准尺寸
```
❌ width=115, height=65
✅ width=120, height=60  # 使用M尺寸
```

## 验证脚本

生成后运行：
```bash
python scripts/validate_drawio.py diagram.drawio
```

重点关注：
- 所有坐标是否为10的倍数
- 节点尺寸是否符合S/M/L标准
- 间距是否使用30/60/120之一
- 同类节点是否对齐
