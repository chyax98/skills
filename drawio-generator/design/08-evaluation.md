# 08: 评测集设计 (Evaluation Suite)

## 一、评测目标

验证 DrawIO 生成器在不同场景下的表现，确保输出质量达标。

---

## 二、评测维度

| 维度 | 权重 | 说明 |
|------|------|------|
| **结构正确性** | 30% | XML 格式正确、可被 DrawIO 打开 |
| **布局合理性** | 30% | 节点不重叠、连线不穿透、对齐良好 |
| **语义准确性** | 25% | 节点和连线符合用户意图 |
| **视觉美观度** | 15% | 整体观感、配色协调 |

## 四、评测方法

### 4.1 自动化评测（结构层）

```python
def evaluate_structure(xml_path: str) -> dict:
    """结构正确性评测"""
    result = validator.validate(xml_path)
    return {
        'xml_valid': not result.errors,
        'error_count': len(result.errors),
        'warning_count': len(result.warnings),
        'node_count': result.stats.get('total_nodes', 0),
        'edge_count': result.stats.get('total_edges', 0),
    }
```

### 4.2 自动化评测（布局层）

```python
def evaluate_layout(xml_path: str) -> dict:
    """布局合理性评测"""
    nodes = parse_nodes(xml_path)

    # 检查重叠
    overlaps = count_overlapping_pairs(nodes, margin=40)

    # 检查对齐
    alignment_score = calculate_alignment_score(nodes)

    # 检查边界
    out_of_bounds = count_out_of_bounds(nodes)

    return {
        'overlap_count': overlaps,
        'alignment_score': alignment_score,  # 0-100
        'out_of_bounds': out_of_bounds,
    }
```

### 4.3 VLM 评测（视觉层）

```python
def evaluate_visual(image_path: str, user_intent: str) -> dict:
    """
    使用 VLM 评测视觉效果

    需要 Claude Vision API 或 GPT-4V
    """
    prompt = f"""
    请评估这张架构图的质量。

    用户意图: {user_intent}

    请从以下维度评分 (1-10):
    1. 布局清晰度：节点排列是否整齐？
    2. 连线可读性：连线是否易于追踪？
    3. 语义准确性：是否准确表达了用户意图？
    4. 整体美观度：配色和风格是否专业？

    输出 JSON:
    {{
      "layout_clarity": <分数>,
      "edge_readability": <分数>,
      "semantic_accuracy": <分数>,
      "visual_appeal": <分数>,
      "overall": <综合分数>,
      "issues": ["问题1", "问题2"],
      "suggestions": ["建议1", "建议2"]
    }}
    """

    # 调用 VLM API
    response = vlm.analyze(image_path, prompt)
    return json.loads(response)
```

## 六、评分标准

### 6.1 结构正确性（30 分）

| 条件 | 得分 |
|------|------|
| XML 格式正确 | 10 |
| 无致命错误 | 10 |
| 无普通错误 | 5 |
| 无警告 | 5 |

### 6.2 布局合理性（30 分）

| 条件 | 得分 |
|------|------|
| 零重叠 | 15 |
| 对齐分数 > 80 | 10 |
| 零越界 | 5 |

### 6.3 语义准确性（25 分）

| 条件 | 得分 |
|------|------|
| 节点数量正确 (±20%) | 10 |
| 边数量正确 (±20%) | 10 |
| VLM 语义评分 > 7 | 5 |

### 6.4 视觉美观度（15 分）

| 条件 | 得分 |
|------|------|
| VLM 布局清晰度 > 7 | 5 |
| VLM 连线可读性 > 7 | 5 |
| VLM 整体美观度 > 7 | 5 |

---

## 七、合格标准

| 等级 | 总分 | 说明 |
|------|------|------|
| **A** | 90+ | 优秀，可直接使用 |
| **B** | 75-89 | 良好，小修后可用 |
| **C** | 60-74 | 及格，需要调整 |
| **D** | <60 | 不合格，需要重构 |

**发布标准**：所有基础用例 ≥ B，80% 中等用例 ≥ B，50% 复杂用例 ≥ C

---

## 八、回归测试

每次代码变更后，重新运行评测集，确保：

1. 结构正确性不下降
2. 布局合理性不下降
3. 无新增失败用例


## 十、持续改进

根据评测结果，持续优化：

1. **失败用例分析** → 找到根因 → 修复
2. **低分用例优化** → 调整 Prompt/参数
3. **新增边缘用例** → 扩展测试覆盖
